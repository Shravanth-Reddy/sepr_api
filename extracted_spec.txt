What currently prevents a genuine end-to-end loop
1 . The evidence endpoint does not use the actual investigation result.
2. The dossier is only generated for SHIP-7010.
3. The main UI parser is heuristic-only.
4. Search fallback can create an incident without live evidence.
5. The dependency chain is not presented as a complete evidence path.
6. Audit records are not durable.
7. LangGraph and standalone agent paths are disconnected from the UI.
Core-loop conclusion
The project is close to a compelling demo, but the most important work is wiring the
existing pieces into one honest path, not adding more modules.

Final demo story
A planner selects an in-transit shipment from the internal operations dataset. The system
generates a shipment-specific SerpApi Google News query and retrieves current external
evidence. The source article, URL, date, and query are shown directly. The system
